# UI

## Naam

De app heet **NoWaste**.

## Logo

<img src="logo.png" alt="NoWaste-logo" width="200">

| Bestand | Formaat | Waarvoor |
|---|---|---|
| [logo.png](logo.png) | 1024 × 1024, transparant | Volledig logo met tekst: login- en splashscherm |
| [ic_launcher_foreground.png](ic_launcher_foreground.png) | 432 × 432, transparant | Voorgrond van het adaptive app-icoon (`mipmap-xxxhdpi`). Het tasje valt binnen de veilige zone, zodat het bij elke icoonvorm volledig zichtbaar blijft. Achtergrond: wit. |
| [ic_launcher_512.png](ic_launcher_512.png) | 512 × 512, witte achtergrond | Icoon voor de Play Store en de README |

Het app-icoon gebruikt enkel het tasje zonder de tekst eronder: op icoongrootte is die tekst niet leesbaar. Maak de icoonbestanden in Android Studio via **File › New › Image Asset** met `ic_launcher_foreground.png` als voorgrond.
